# Workflow Logic

## Documented workflows
- Module record workflow: select an existing Database record to load it into the Form; use the Form for create, update or delete.
- Role deletion workflow: reassign users before deleting a role that has assigned users.
- Settings workflow: manage module slugs, Account layout slugs, website identity and approved preferences.
- Home customization workflow: choose which supported sections appear on Home.

## Pending Specification
Exact step-by-step confirmation screens, cancellation behavior, rollback, notifications, audit events, bulk operations, import/export and approval workflows are not yet defined.
