# Authentication

## Platform

Use Supabase Authentication.

## Existing flows

Preserve the working Supabase Authentication system and existing authentication flows.

Account creation, login, password reset and password change must use secure authentication flows.

## Profile linkage

Maintain the relationship between Supabase Auth users and profile records.

## Password handling

- Never expose passwords in the Dashboard.
- Do not store or reveal passwords through ordinary profile or administrative forms.
- Password changes and resets must use secure authentication flows.
