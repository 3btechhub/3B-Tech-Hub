# Privacy and Analytics

## Separate concerns

Keep Visitor Analytics and administrative Activity Logs as separate concerns where those existing capabilities are retained.

## Permitted analytics data

Analytics may include:

- Page views
- Unique and repeat visitors
- Timestamps
- Device
- Operating system
- Browser
- Approximate country and city

## IP and location privacy

- Never store raw IP addresses.
- Disclose third-party IP geolocation processing.
- Label location as approximate rather than GPS.
- Show the required ipdata attribution wherever its data is displayed.
- Reuse a visitor location for 24 hours.
- Restrict analytics access to Owner.
- Retain analytics for 90 days.
