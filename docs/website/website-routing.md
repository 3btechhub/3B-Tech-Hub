# Website Routing

## Configurable slugs

- Each Dashboard module has its own configurable slug.
- Each Account layout has its own configurable slug.
- Slugs are managed inside Settings.

A module slug identifies the module within the Dashboard. It does not create an independent standalone page.

Account layout slugs identify layouts within the Account experience; they do not create additional primary pages.

Changing a slug must not break data identity, relationships or authorization.

See [Website Settings](../settings/website-settings.md).
