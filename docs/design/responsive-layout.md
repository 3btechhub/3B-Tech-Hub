# Responsive Layout

## Mobile-first

The website and Dashboard must be responsive and mobile-first.

## Component sizing

Use only Small, Medium and Large semantic sizes.

Keep equivalent inputs, outputs, buttons and cards consistent in size at each responsive breakpoint.

Content length must not resize standard components. Wrap, truncate or scroll content within defined dimensions.

Responsive layout changes may adapt to viewport width.

## Shared layout

The shared website shell consists of Header, Content and Footer. Keep these regions separate and reusable.

## RTL readiness

Keep architecture ready for future RTL support through CSS logical properties, inherited direction and direction-aware reusable components.

Do not activate an RTL/LTR switch or language-based direction switching without explicit approval.
