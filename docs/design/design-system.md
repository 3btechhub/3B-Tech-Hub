# Design System

## Visual direction

Use a clean, uncluttered visual hierarchy with restrained use of text.

Prefer:

- Cards
- Buttons
- Clearly labeled input and output controls
- Distinct, meaningful icons for different modules and actions

## Theme and palette

- Black, White and Neutral Gray palette
- Light and Dark themes

## Consistency

Maintain consistent spacing, typography, borders, focus states and touch targets.

Use the semantic component sizes Small, Medium and Large. The default component size is Medium.

See [Project Direction](../project/project-direction.md) and [Accessibility](accessibility.md).
