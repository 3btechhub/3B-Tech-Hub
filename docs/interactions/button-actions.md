# Button Actions

## Known action groups
- Module Form: create, update and delete.
- Database: select a record to load it into the Form; rearrange records.
- User/Role/Permission status actions: Active, Deactive, Block and Delete where applicable.
- Settings: save approved website identity, slug and preference changes.
- Home Customizations: enable or disable supported Home sections.

## Pending Specification
Exact button labels, confirmation requirements, disabled/loading states, success feedback, error feedback, keyboard behavior and undo behavior must be specified per action. Do not infer destructive-action confirmation behavior.
