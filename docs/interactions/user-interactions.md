# User Interactions

## Confirmed interaction patterns
- Home cards show an image or fallback icon and a title.
- Module Database selection loads a record into its Form.
- Database entries support rearrangement.
- Users can switch to another available language; English is pre-created/default.
- Light and Dark themes are supported.

## Pending Specification
Hover/focus states, touch gestures, drag-and-drop mechanics, keyboard shortcuts, notifications, tooltips, modal behavior, empty states and feedback timing are not comprehensively specified.
