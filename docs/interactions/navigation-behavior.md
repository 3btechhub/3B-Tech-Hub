# Navigation Behavior

## Confirmed
- Primary pages: Home, Account and Dashboard.
- Dashboard modules are embedded modules, not independent pages.
- Module slugs are configurable in Settings.
- Account layout slugs are configurable in Settings.
- Header, Content and Footer have separate layout specifications.

## Pending Specification
Exact menu items by authentication state, active-item rules, browser back/forward behavior, unknown-slug handling, redirects, unsaved-change navigation guards and deep-link behavior require explicit definition.
