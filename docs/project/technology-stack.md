# Technology Stack

## Approved platforms

- **GitHub** — source code and version control
- **Supabase** — PostgreSQL database, Authentication, Storage and backend services

Do not introduce another hosting or backend platform without explicit approval.

## Existing resource preservation

Preserve the working Supabase Authentication system, database security, existing data and Storage objects.

Use additive, reversible migrations wherever practical. Review [Change Control and Delivery](change-control.md) before modifying project resources.
