# Project Overview

## Purpose

Build a clean, professional, responsive, modular website with a dashboard-driven content management system.

The project combines a public-facing website with account access and an Owner-controlled Dashboard.

## Primary website pages

- Home
- Account
- Dashboard

These are the only primary website pages in the current specification.

## Core capabilities

- Public Home content sourced from approved catalogue modules
- Account and authentication layouts
- Owner-only Dashboard access
- Structured catalogue and access-management modules
- Configurable module and account-layout slugs
- Reusable shared layouts and components

## Product principles

- Simple, modular, secure and maintainable
- Reusable components
- Clear forms, database lists, buttons and cards
- Ready for future expansion without activating unapproved features
