# Fixed Defaults and Protected Selections

## Country default

Global is checked by default and cannot be unchecked or removed from a record's country selection.

Other available countries can be independently checked or unchecked.

The Global country record is a protected system record and must not be deleted or renamed.

## Visibility default

Owner is checked by default and cannot be unchecked.

Other available visibility values can be independently checked or unchecked.

## Language default

English is pre-created and selected as the default language. If additional languages exist, the user can switch to another available language.

## Enforcement

Enforce defaults and protections in both the interface and trusted database/backend logic.
