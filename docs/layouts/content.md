# Content Layout

## Purpose

Content is the central page-content region between the shared Header and Footer.

It hosts the content belonging to the active primary page:

- Home content
- Account layouts
- Dashboard modules

## Content ownership

Page-specific content and behavior are specified in their own topic files. The shared Content layout must not duplicate or redefine those requirements.

## Layout boundaries

Content is a separate shared layout region. Keep it independent from Header and Footer and allow the active page to render within it.

No additional global content elements or interactions are approved in this specification.
