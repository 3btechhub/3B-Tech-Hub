# Home Customizations

## Purpose

Manage which supported modules appear on Home and their order.

## Available choices

- Service Types
- Product Types
- Services
- Products
- Workshops
- Technicians
- Countries
- Languages

## Default Home modules

By default, Home displays:

- Service Types
- Product Types
- Services
- Products
- Workshops
- Technicians

Countries and Languages are available in the customization choices but must not be added to the default Home display unless enabled by the Owner.

## Controls

Customizations manages:

- Module on Home
- Show / Hide
- Rearrange

Changes update Home visibility and order without creating standalone pages. Hidden modules must not render publicly. Respect configured visibility rules.

## Home card content

Home cards show only:

- The item's uploaded image or a suitable fallback icon
- The item's title

Uploaded images take precedence over fallback icons. Do not show descriptions or unrelated metadata on these cards.

Keep section titles clear and centered, with consistent responsive spacing.
