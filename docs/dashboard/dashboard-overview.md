# Dashboard Overview

## Purpose

Dashboard is the Owner-controlled management area of the website.

Dashboard access is visible only to the Owner, and backend authorization must enforce that access.

## Module order

The Dashboard contains these modules in this order:

- Overview
- Website Informations
- Service Types
- Product Types
- Services
- Products
- Workshops
- Technicians
- Countries
- Languages
- Users
- Roles
- Permissions
- Customizations
- Settings

Each module has its own configurable slug managed in Settings. A module slug does not create a standalone page.

## Module interface

The eleven data modules listed below use the shared Form and Database interface:

- Service Types
- Product Types
- Services
- Products
- Workshops
- Technicians
- Countries
- Languages
- Users
- Roles
- Permissions

See [Module Interface Standard](module-interface-standard.md).
