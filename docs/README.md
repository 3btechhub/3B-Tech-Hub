## Documentation conventions

- Keep each document in its existing topic folder.
- Use lowercase, hyphen-separated names for new Markdown files.
- Link related documents rather than duplicating the same specification.
- Update this index whenever a document or topic folder is added, renamed, or removed.
- Mark unfinished specifications clearly; do not treat empty placeholders as completed requirements.
