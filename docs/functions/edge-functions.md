# Edge Functions

## Scope
Supabase Edge Function contracts and operational behavior belong here.

## Security expectations
Use trusted server-side validation and authorization for privileged operations. Never treat client-supplied role, Owner or permission claims as authoritative.

## Pending Specification
The exact Edge Function inventory, names, routes, JWT settings, request/response schemas, secrets, external integrations, timeout/retry rules and deployment configuration are not yet defined in the product specification. Verify deployed functions before describing implementation state.
