# Frontend Functions

## Scope
This file is the specification register for browser/client-side functions.

## Confirmed user-facing capabilities
- Render the three primary pages and their approved layouts.
- Render Dashboard modules within Dashboard.
- Render module Form + Database interfaces.
- Load a selected Database record into its Form.
- Allow Database rearrangement.
- Render configurable Home sections and Light/Dark themes.

## Function contracts pending
No named frontend function signatures, parameters, return types, error contracts or source modules have been approved. Do not invent function names or implement undocumented behavior. Add each future function with purpose, trigger, inputs, outputs, side effects, authorization assumptions and tests.
