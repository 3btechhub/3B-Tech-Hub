# Account Overview

## Account layouts

Account contains these layouts:

- Login
- Create Account
- Reset Password
- Profile

Each layout has its own configurable slug. These are layouts within the Account experience, not additional primary website pages.

## Authentication requirements

- Preserve the existing authentication flows.
- Do not expose passwords in the Dashboard.
- Password changes and resets must use secure authentication flows.

See the individual layout files and [Authentication](../security/authentication.md).
